# Projeto base: Ponto de partida (o TaskLab do Sábado 2)

**Antes do bloco 1.** É o aplicativo com que começamos: lista de tarefas com o composable useTasks, o formulário e o item de lista. Ainda não há store, Router, persistência nem IA. Nos arquivos há marcadores escritos “BLOCO N” que mostram onde cada passo vai acontecer.

## Como conferir

- npm install e npm run dev abrem o aplicativo.
- Adicionar uma tarefa a coloca na lista e aumenta o contador de pendentes.
- Marcar uma tarefa diminui o contador.

## Como rodar

```bash
npm install
npm run dev
```
